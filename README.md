# 🐧 CaLvo.OS

### 💻 Sin pelo, sin problemas.

**CaLvo.OS** es un proyecto de distribución Linux personalizada, basada en **Debian 13 (Trixie)**, desarrollado con fines educativos y de aprendizaje sobre sistemas operativos.

Nuestro objetivo es construir una distribución Linux propia, desde una versión mínima hasta un sistema con interfaz gráfica, personalización e identidad visual.

## 🎯 Objetivos del proyecto

- ✅ Crear una distribución mínima basada en Debian.
- ✅ Generar nuestra primera imagen ISO.
- ✅ Publicar el código fuente en GitHub.
- ✅ Publicar la primera ISO descargable.
- ⏳ Verificar el arranque en VirtualBox.
- ⏳ Diseñar una identidad visual propia.
- ⏳ Desarrollar una edición gráfica basada en X11/i3.
- ⏳ Explorar una futura edición Wayland.
- ⏳ Incorporar un instalador.
- ⏳ Mejorar la experiencia de usuario y la personalización.

## 🛠️ Tecnologías utilizadas

- Debian GNU/Linux 13 (Trixie)
- Linux
- Live-Build
- Git y GitHub
- Oracle VirtualBox
- Herramientas GNU/Linux
